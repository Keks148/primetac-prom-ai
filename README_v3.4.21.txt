PrimeTac AUTO v3.4.21 STRICT IDENTITY

Исправление ложных семей разновидностей из-за совпадения числовых ID между разными XML-фидами.

Главное:
- supplier offer id и Prom external_id больше не считаются достаточным доказательством совпадения сами по себе;
- для numeric ID требуется независимое подтверждение моделью/названием и отсутствие конфликта типа товара;
- точный SKU/артикул остаётся сильным идентификатором;
- тест разновидности дополнительно сверяет каждый Prom-товар с его XML-товаром;
- preview показывает обе стороны сопоставления и причину/сходство;
- несовместимые типы (например куртка ↔ кроссовки) блокируются до любого импорта.

Массовое восстановление разновидностей по-прежнему не включено.
