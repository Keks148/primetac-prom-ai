PrimeTac AUTO v3.4.10 CREATE GROUPS SAFE

1. only_update=false для единого YML-импорта групп/характеристик. Это позволяет Prom создать недостающие непустые группы из <categories>.
2. Безопасность: offers строятся только из товаров, только что прочитанных из текущего каталога Prom; товары без external_id пропускаются. updated_fields остаётся только group + attributes; mark_missing_product_as=none.
3. PARTIAL больше не держит lock бесконечно: если не менее 20 минут все позиции уже учтены status API, created=0, updated=0, errors=0 и каталог не изменился, задача классифицируется PARTIAL_NO_EFFECT и lock снимается.
4. После восстановления старого lock v3.4.9 новая версия сама проверит его и сможет освободить, если он соответствует условиям PARTIAL_NO_EFFECT.
5. Перед only_update=false добавлена проверка уникальности external_id; при дублях импорт останавливается до отправки.
6. После истечения фонового тайм-аута программа всё равно делает один финальный запрос status + проверку каталога, чтобы старый PARTIAL после рестарта не зависал навечно.
