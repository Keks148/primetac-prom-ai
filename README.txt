PrimeTac Card Manager v1.7 MASS
=================================

Это массовая версия после подтверждённой рабочей записи UA keywords.

Новые кнопки:
- Исправить 25
- Исправить 100
- Исправить ВСЕ безопасно
- Стоп

Что означает "безопасно":
Автоматически меняются ТОЛЬКО украинские поисковые запросы через
PUT /products/translation с product_id + lang=uk + keywords.

После КАЖДОГО товара программа снова читает Prom.
Успех засчитывается только если Prom реально вернул новые UA keywords.

Не меняются:
- цены
- остатки
- наличие
- названия
- описания
- фото
- категории
- производитель
- цвет
- размер
- вид товара
- вес

Card Manager всё это ПРОВЕРЯЕТ и показывает рекомендации,
но массово не трогает.

Настройки Render:
PROM_TOKEN=...
WRITE_ENABLED=true
MAX_PRODUCTS=5000
KEYWORD_MIN=5
SCAN_CONCURRENCY=5
FIX_CONCURRENCY=2
VERIFY_DELAY_MS=700
BATCH_SIZE=25

Как запускать:
1. Deploy.
2. Сканировать весь каталог.
3. Для первой проверки можно "Исправить 25".
4. Если всё нормально — "Исправить ВСЕ безопасно".
5. На экране виден прогресс и количество подтверждённых изменений.
6. "Стоп" завершит текущие запросы и не начнёт новые.

FIX_CONCURRENCY=2 выбран специально, чтобы не долбить Prom API слишком агрессивно.
