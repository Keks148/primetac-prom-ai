PrimeTac Variant Dedup Fix v1.8.3

Исправление после контрольного CSV-импорта:
- если несколько позиций поставщика отличаются только кодом / SKU / ID, в Prom экспортируется ОДИН товар;
- внутренние коды больше не превращаются в фальшивую характеристику «Варіант»;
- реальные разновидности (размер, цвет и другие реально меняющиеся характеристики) сохраняются;
- если у семейства несколько строк, но нет понятной характеристики разновидности и строки НЕ являются точными дублями, семейство пропускается как ambiguous, чтобы не засорять Prom;
- группы Prom не создаются и не меняются;
- товары без фото по-прежнему не экспортируются;
- сертификаты BEZET по-прежнему исключаются предыдущим фильтром.

Новые счетчики в summary:
- collapsedCodeOnlyFamilies — семейства, где дубли по кодам схлопнуты в 1 товар;
- skippedAmbiguousFamilies — подозрительные семейства, которые безопасно пропущены;
- realVariantFamilies — реальные семейства с разновидностями.

PROM_CSV_TEST_IMPORT_ON_START оставить false до проверки /feeds/prom-test.csv.
Уже созданные в Prom лишние разновидности автоматически не удаляются этой версией. Сначала проверяем новый CSV, затем отдельно чистим старые дубли.
