PrimeTac Card Manager v1.9 SUPPLIER AUTOFILL

Главное исправление:
- цифра "нужно исправить" для ключей больше не подменяет все незаполненные поля.
- 4 UA поисковых запроса считаются достаточными, поэтому 7 зацикленных товаров не гоняются снова.
- аудит теперь отличает реальные поля Prom от предположений по названию.
- после сопоставления поставщиков показывается, сколько товаров и полей реально можно дополнить.

Автозаполнение характеристик:
1. Сначала нажать "Загрузить + сопоставить".
2. Нажать "ТЕСТ 1 характеристики".
3. Тест меняет ровно одно пустое существующее поле Prom и перечитывает товар.
4. Только если Prom подтвердил изменение, становится доступна кнопка "Заполнить характеристики".
5. Массовый режим не создаёт неизвестные характеристики. Он меняет только те records из Prom attributes, которые уже существуют и пусты.

Размер:
- автоматически записывается только если у конкретной позиции поставщика найден ровно один размер.
- если фид отдаёт сразу S,M,L,XL для одной позиции, размер не записывается, чтобы не испортить разновидности.

Описание:
- отдельная кнопка дополняет только короткие/пустые UA описания, если фид поставщика содержит более подробное описание.

Не меняются:
- цена
- остаток
- наличие (передаётся только текущее presence, если Prom требует его при edit)
- фото
- группа/категория
