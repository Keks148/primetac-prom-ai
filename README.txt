PrimeTac Scheduler v1.4.4

Что меняется:
- BEZET по-прежнему НЕ фильтруется.
- MILITARIS фильтруется как в v1.4.3.
- Новые нормальные товары Militaris (одежда/обувь) имеют приоритет.
- Если каталог приближается к 1000 карточкам, аксессуары автоматически сокращаются первыми.
- Ночное/дневное расписание теперь фиксировано по Europe/Kyiv:
  04:00
  08:00
  11:00
  14:00
  17:00
  20:00
  23:00
  То есть днем примерно каждые 3 часа, ночью один 5-часовой интервал 23:00 -> 04:00.
- На каждом слоте запускается аудит и повторный расчет отобранного каталога.

ВАЖНО:
Текущая версия все еще READ_ONLY.
Она контролирует отбор и расписание, но пока не отправляет товары в Prom.
