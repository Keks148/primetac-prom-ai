PrimeTac AUTO v3.2 FEED STABLE

Эта версия исправляет конкретную ошибку со скриншота:
BEZET: This operation was aborted

Причина:
в v3.1 фид скачивался через fetch + AbortController с жёстким лимитом 90 секунд.
Если BEZET отвечал или скачивался дольше, программа сама обрывала загрузку.

Что изменено:
- BEZET/Militaris теперь скачиваются через native HTTP/HTTPS streaming;
- НЕТ жёсткого 90-секундного обрыва;
- idle timeout по умолчанию 5 минут;
- общий предел одной загрузки 20 минут;
- на экране виден реальный объём: «Загружаю BEZET: 4.8 МБ»;
- автоматически пробуется вариант домена с www / без www;
- успешный XML сохраняется во временный кеш;
- если следующий 4-часовой запуск временно не может получить свежий XML, можно использовать успешный кеш до 24 часов;
- если после deploy кеша ещё нет и BEZET реально недоступен, запись в Prom НЕ начинается;
- обе базы поставщиков по-прежнему обязательны;
- единый импорт каталога из v3.1 сохранён.

ВАЖНО ДЛЯ RENDER:
Старый SUPPLIER_FEED_TIMEOUT_MS теперь не используется для загрузки фидов.
Даже если в Render остался SUPPLIER_FEED_TIMEOUT_MS=90000, он не сможет снова оборвать BEZET.

Обязательные:
PROM_TOKEN=...
WRITE_ENABLED=true

Необязательные:
AUTO_ON_START=true
AUTO_INTERVAL_HOURS=4
FEED_IDLE_TIMEOUT_MS=300000
FEED_TOTAL_TIMEOUT_MS=1200000
FEED_CACHE_HOURS=24
AUTO_IMPORT_STATUS_MAX_MIN=90

Можно удалить старые переменные:
SUPPLIER_FEED_TIMEOUT_MS
AUTO_IMPORT_CHUNK

Цены, остатки, наличие и фотографии товаров не меняются.
