PrimeTac Group — SEO Keywords Auto Manager v1.0

ЧТО ДЕЛАЕТ
- Загружает товары Prom.ua через официальный API.
- Сам определяет тип товара по названию.
- Формирует 3–7 релевантных поисковых фраз на украинском.
- По умолчанию заполняет только товары, у которых поле "Пошукові запити" пустое.
- Есть предпросмотр перед массовой записью.
- Может запускаться автоматически по расписанию.

НЕ МЕНЯЕТ
Цена, наличие, название, описание, фото, группы и категории.

УСТАНОВКА
1. Положи primetac-seo-keywords.js в корень Node/Express проекта рядом с server.js.
2. После app.use(express.json()) добавь:

const installPrimeTacSeo = require('./primetac-seo-keywords');
installPrimeTacSeo(app);

3. На Render должны уже быть:
PROM_TOKEN=...
WRITE_ENABLED=true
WRITE_PIN=твой_PIN

4. После деплоя открой:
https://ТВОЙ-САЙТ/seo-keywords

5. Первый запуск:
- режим "Только без ключевых фраз";
- "Проверить товары";
- посмотри предпросмотр;
- введи WRITE_PIN;
- "Применить".

АВТОРЕЖИМ
После успешного ручного теста добавь в Render:
SEO_AUTORUN=true
SEO_AUTORUN_MODE=missing
SEO_INTERVAL_HOURS=12

Тогда раз в 12 часов модуль будет заполнять новые товары, у которых ключевые фразы пустые.

РЕЖИМЫ
missing — только без ключевых фраз (рекомендую).
weak — пустые + где меньше 3 фраз.
all — пересоздаёт фразы всем товарам.

ВАЖНО
Prom рекомендует релевантные поисковые запросы. Поэтому модуль не пишет один и тот же набор на все 1000 карточек, а строит фразы из типа товара, бренда, модели и цвета.
