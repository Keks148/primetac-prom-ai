PrimeTac Editor v2.1.0

Что добавлено:
1. Финальный безопасный фильтр:
   - оставляет одежду, обувь, головные уборы и перчатки;
   - LOWA и Helikon-Tex блокируются;
   - снаряжение, броня, каски, очки, сумки/рюкзаки, оружейные ремни,
     подсумки, кобуры, ножи, шевроны и т.д. скрываются через 0 шт.;
   - сертификаты, термоодеяла и маскировочные сетки тоже исключаются;
   - "шапка-подшлемник" сохраняется как головной убор.

2. Ключевые слова:
   - автоматическое заполнение;
   - до 255 символов;
   - RU + UA поисковые фразы;
   - нормальные фразы без бессмысленной простыни слов.

3. Группы:
   - определяется правильная группа по названию товара;
   - брюки не зависят от ошибочной группы "Кобури та кріплення";
   - исправление группы выполняется отдельным enrichment-импортом.

4. Характеристики:
   - берутся реальные <param> из XML BEZET/MILITARIS;
   - добавляются только безопасно выводимые данные: бренд, тип, цвет,
     пол, сезон, страна;
   - до 10 характеристик;
   - ничего не выдумывается.

5. SEO:
   - enrichment CSV формирует HTML-заголовок и HTML-описание RU/UA.
   - В автоматическом импорте пока обновляются только group/keywords/attributes/translations.
     SEO-поля уже есть в CSV, их можно включить после контрольного импорта.

6. Безопасность:
   - импорт только обновляет существующие товары: only_update=true;
   - отсутствующие товары не трогаются: mark_missing_product_as=none;
   - цена/остаток/наличие импортом enrichment не обновляются;
   - PROM_EDITOR_APPLY=false и PROM_ENRICH_IMPORT_APPLY=false оставить
     до проверки dry-run.

Загрузить поверх репозитория:
- editor-server.js
- src/prom-editor.js
- src/enrichment-import.js
