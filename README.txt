PrimeTac AUTO v3.4.4 FINAL WAIT

Главное исправление: автомат больше не показывает «Готово» только потому, что Prom принял импорт в фоне.

Что изменено:
- после POST /products/import_file сохраняется ID импорта;
- GET /products/import/status/{id} опрашивается каждые 20 секунд;
- обычные ошибки status endpoint НЕ завершают процесс;
- основное ожидание по умолчанию — до 15 минут;
- параллельно автомат перечитывает каталог Prom и сверяет фактические group_id с планом;
- если импорт всё ещё не подтверждён, включается фоновая проверка;
- пока предыдущий импорт не подтверждён, кнопка нового импорта и плановый импорт блокируются;
- если Prom сообщает, что другой импорт уже выполняется, второй импорт НЕ отправляется;
- Stock Monitor также ждёт окончания фонового импорта;
- после Render Deploy новый импорт по умолчанию не стартует автоматически, чтобы не продублировать старую задачу;
- счётчики ключей и описаний теперь отдельно показывают, сколько товаров реально проверено;
- «Группы подтверждены» теперь означает совпадение товара с конкретной группой из текущего плана, а не просто наличие товара в любой управляемой группе.

Render — обязательные переменные:
PROM_TOKEN=...
WRITE_ENABLED=true
AUTO_INTERVAL_HOURS=4

Необязательно:
AUTO_IMPORT_STATUS_MAX_MIN=15
AUTO_STATUS_POLL_SEC=20
AUTO_STATUS_VERIFY_SEC=60
AUTO_BACKGROUND_WATCH_MAX_MIN=120
AUTO_ON_START=false

AUTO_ON_START=false рекомендуется оставить. Автоматический цикл всё равно работает каждые AUTO_INTERVAL_HOURS.

Безопасность:
- цены и фото этот импорт не меняет;
- массовая запись остатков по-прежнему зависит от STOCK_WRITE_ENABLED;
- при сомнительном состоянии Prom новый импорт не запускается поверх предыдущего.

Проверка проекта:
npm run check
