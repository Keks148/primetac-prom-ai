PrimeTac AUTO v2.0 SIMPLE

Полная замена файлов.

Что делает одна кнопка:
1) Сканирует весь каталог Prom.
2) Загружает BEZET + Militaris и сопоставляет товары.
3) Дополняет украинские поисковые запросы там, где их мало.
4) Дополняет только слабые/короткие описания более полным описанием поставщика.
5) Формирует YML с характеристиками и отправляет в официальный Prom API /products/import_file с updated_fields=[attributes], only_update=true.
6) Проверяет статус /products/import/status/{id}.
7) Повторяет автоматически каждые 6 часов.

НЕ меняет: цены, остатки, наличие, фото.

Render обязательно:
PROM_TOKEN=...
WRITE_ENABLED=true

Необязательно:
AUTO_INTERVAL_HOURS=6
AUTO_ON_START=true

Ссылки BEZET и Militaris уже встроены по умолчанию.

Если Prom отклонит импорт характеристик, открой /auto/last-import.xml — файл сохраняется для диагностики, а остальные этапы (ключи/описания) всё равно работают.
