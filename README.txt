PrimeTac Product Enrichment v1.6.0

Что добавлено
-------------
1. Постоянный enrichment-cache на Render Disk:
   /var/data/primetac-enrichment-cache.json

2. Для каждой выбранной карточки автоматически подготавливаются:
   - название UA;
   - название RU;
   - описание UA;
   - описание RU;
   - поисковые запросы/keywords UA;
   - поисковые запросы/keywords RU;
   - SEO title/description как заготовка;
   - фото (до 10);
   - характеристики;
   - разновидности;
   - бренд, артикул, страна, штрихкод, если поставщик их передает;
   - точная существующая группа Prom.

3. Стабильность при обновлениях:
   - цена, наличие, остатки, фото и варианты считаются динамическими;
   - готовое описание НЕ генерируется заново на каждом обновлении;
   - если исходное название/категория/бренд/описание/статические характеристики не изменились,
     используется сохраненный enrichment из /var/data;
   - если реально изменилась смысловая информация товара, карточка получает
     METADATA_AND_DYNAMIC;
   - обычное плановое обновление существующего товара получает DYNAMIC_ONLY;
   - новый товар автоматически получает FULL и полностью допиливается;
   - если товар исчез и позже вернулся, его старое описание сохраняется в cache.

4. Подготовка к будущему импортеру:
   updateMode:
   - FULL = новый/еще не опубликованный товар;
   - METADATA_AND_DYNAMIC = смысловые данные изменились;
   - DYNAMIC_ONLY = менять только цену/наличие/остаток/фото/варианты,
     не трогая стабильное описание и keywords.

5. Все прежние правила сохранены:
   - сертификаты BEZET не добавляются;
   - товары без фото не добавляются;
   - товары без названия не добавляются;
   - MILITARIS: от 500 грн, без шлемов, плит, оружейных магазинов/боеприпасов,
     без Helikon-Tex и обуви LOWA;
   - группы Prom не создаются автоматически;
   - READ_ONLY пока сохраняется.
