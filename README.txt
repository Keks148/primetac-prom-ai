PrimeTac Card Manager v1.9.3 SERVER MODE

Главное:
основные действия больше не зависят от JavaScript браузера.

Без JavaScript работают:
- Сканировать весь каталог
- Обновить статус
- Загрузить + сопоставить BEZET + Militaris
- Только обновить фиды
- Только сопоставить
- ТЕСТ 1 характеристики
- Заполнить характеристики
- Дополнить пустые описания

Статус выводится прямо сервером Render.
Во время сканирования/сопоставления/заполнения страница сама обновляется каждые 3 секунды.

В Render обязательны:
PROM_TOKEN=...
WRITE_ENABLED=true

Ссылки BEZET и Militaris уже есть в коде по умолчанию.
