PrimeTac SEO AUTO ONLY — ПОЛНАЯ ЗАМЕНА
==========================================

Эта версия специально сделана вместо старого PrimeTac Prom AI v11.

УДАЛЕНО ПОЛНОСТЬЮ:
- +20% к цене;
- Price Guard;
- автоматическая правка цен;
- старая логика Militaris;
- любая логика BEZET по цене;
- AI-редактор;
- менеджер прибыли;
- старые инструменты.

ОСТАЛОСЬ ТОЛЬКО:
- Prom.ua;
- автоматическая проверка товаров;
- автоматическое добавление поисковых фраз;
- простой экран контроля.

ВАЖНО ПРО ДВА КАТАЛОГА
----------------------
Не имеет значения, пришёл товар из BEZET или Militaris.
Сайт получает уже существующие товары из твоего Prom и работает с обоими.
Он НЕ меняет поставщика, цену, наличие, описание или импорт.

КАК ЗАМЕНИТЬ СТАРЫЙ ПРОЕКТ
---------------------------
1. Скачай этот ZIP.
2. Распакуй.
3. В GitHub-репозитории старого PrimeTac Prom AI удали старые файлы.
4. Загрузи файлы из этого архива В КОРЕНЬ репозитория:
   - server.js
   - package.json
   - .gitignore
   - .env.example
   - README.txt

5. Render должен использовать:
   Build Command:
   npm install

   Start Command:
   npm start

6. В Render -> Environment оставь/добавь:
   PROM_TOKEN=твой токен
   WRITE_ENABLED=true
   SEO_AUTORUN=true
   SEO_INTERVAL_HOURS=6

7. Удали из Environment старые переменные, если хочешь:
   PRICE_GUARD_*
   MILITARIS_*
   OPENAI_MODEL
   OPENAI_WEB_MODEL
   и т.д.

   OPENAI_API_KEY для этой версии вообще не нужен.

КАК РАБОТАЕТ
------------
После нового Deploy открываешь обычный адрес Render.

Например:
https://primetac-prom-ai.onrender.com/

На экране будет только PrimeTac SEO Auto.

Первый автоматический запуск происходит примерно через 60 секунд после старта.
Потом каждые 6 часов.

Сайт меняет ТОЛЬКО товары, у которых поле поисковых фраз пустое.
Уже заполненные ключевые слова он НЕ переписывает.

РУЧНАЯ ПРОВЕРКА
---------------
На главной странице есть:
- "Проверить сейчас" — ничего не меняет, только показывает результат;
- "Заполнить недостающие ключи" — запускает заполнение сразу.

БЕЗОПАСНОСТЬ
------------
Даже если SEO_AUTORUN=true, запись в Prom работает только при:
WRITE_ENABLED=true

То есть аварийная остановка:
WRITE_ENABLED=false
