PrimeTac UA Keywords Writer v1.4 TEST
======================================

ПОЧЕМУ v1.3 НЕ МЕНЯЛА ТО, ЧТО НУЖНО
------------------------------------
По скриншоту Prom видно:

Пошукові запити (Українські) — ПУСТО
Пошукові запити (Російські) — уже есть "Чоловічий одяг"

v1.3 работала с обычным products/list -> keywords и POST /products/edit.
Это не заполняло пустое украинское поле карточки.

В официальном API Prom есть отдельные методы перевода товара:
GET /products/translation/{id}?lang=uk
PUT /products/translation

v1.4 тестирует именно их.

ВАЖНО
-----
Это НЕ массовая версия.
Одно нажатие "ТЕСТ: записать 1 товар" меняет только один товар.

Порядок:
1. Полностью замени текущие файлы проекта файлами из архива.
2. Render:
   Build Command: npm install
   Start Command: npm start
3. Environment нужен:
   PROM_TOKEN=твой текущий токен
4. Открой сайт.
5. Он сам найдёт товар.
6. Посмотри "Сейчас UA keywords" и "Предлагаем записать".
7. Нажми "ТЕСТ: записать 1 товар".
8. Смотри результат:
   - ПОДТВЕРЖДЕНО = повторный GET Prom реально вернул новые keywords.
   - НЕ ПОДТВЕРЖДЕНО = PUT принят, но поле не изменилось.
   - Prom отклонил запись = внизу будет точный HTTP-ответ/ошибка.

После ПОДТВЕРЖДЕНО уже можно делать массовую версию.

Эта версия НЕ меняет:
- цену
- остатки
- наличие
- название основного товара
- описание основного товара
- фото
- категории
- характеристики

В PUT перевода name/description отправляются только как уже существующие
украинские значения без изменений, если Prom их вернул.
