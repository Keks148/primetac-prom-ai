PrimeTac SEO AUTO ONLY v1.1 FIX
================================

ПОЧЕМУ ПРЕДЫДУЩАЯ ВЕРСИЯ ПОКАЗЫВАЛА 1611 / 1611
------------------------------------------------
В предыдущей версии любое значение product.keywords преобразовывалось через String(...).
Если Prom возвращал поле как объект, например {}, JavaScript превращал его в:
[object Object]

И программа ошибочно считала это одним ключевым словом.

Поэтому она показывала:
1611 товаров
1611 с ключами
0 без ключей

и НИЧЕГО не записывала, потому что считала каталог уже заполненным.

ЧТО ИСПРАВЛЕНО
--------------
- объект больше никогда не считается ключевыми словами;
- понимаются keywords, search_keywords, searchKeywords;
- считаются только реальные строки/массивы строк;
- после /products/edit программа проверяет errors;
- учитывается processed_ids;
- после записи программа снова читает Prom и показывает:
  "Подтверждено повторным чтением".

КАК ЗАМЕНИТЬ
------------
Просто снова замени файлы в GitHub на файлы из этого архива.
Render автоматически сделает deploy.

Environment:
PROM_TOKEN=...
WRITE_ENABLED=true
SEO_AUTORUN=true
SEO_INTERVAL_HOURS=6

ПОСЛЕ DEPLOY
------------
1. Открой сайт.
2. Нажми "Проверить сейчас".
3. Теперь должно показать реальное количество "Без ключей".
4. Только после этого нажми "Заполнить недостающие ключи".
5. Смотри строку "Подтверждено повторным чтением".

ВАЖНО
-----
В кабинете Prom индикатор качества 90% может обновляться не в ту же секунду.
Поэтому после записи:
- открой конкретный товар;
- проверь поле "Пошукові запити";
- затем обнови список товаров через несколько минут.

Программа НЕ меняет:
цены, остатки, названия, описания, фото, характеристики и поставщиков.
