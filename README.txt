PrimeTac Card Manager v1.6
=============================

Это объединённая версия после успешного теста v1.4.1.

Что уже работает
----------------
Рабочая запись украинских поисковых запросов:
PUT /products/translation

payload:
product_id
lang = uk
keywords

После записи программа снова читает Prom и считает изменение успешным
только если Prom реально вернул новые UA keywords.

Что проверяет Card Manager
--------------------------
Название
Описание
Ключевые слова UA
Производитель
Вид товара
Цвет
Размер
Категория
Вес
Фото

Для каждого товара считается процент заполнения.

Что можно делать
----------------
1. Сканировать весь каталог.
2. Искать товар по названию.
3. Фильтровать:
   - нет UA ключей
   - нет производителя
   - нет типа
   - нет цвета
   - нет размера
   - нет категории
   - нет веса
   - мало фото
   - заполнение <= 60%
4. Открывать карточку и видеть:
   текущее значение + рекомендацию.
5. Исправлять UA keywords у одного товара.
6. Исправлять безопасно партиями по 25 товаров.

ВАЖНО
-----
Автоматически изменяются ТОЛЬКО украинские поисковые запросы.

Пока НЕ записываются автоматически:
- производитель
- вид товара / вид куртки
- цвет
- размер
- категория
- вес

Причина: это могут быть категорийные характеристики Prom со своими ID
и допустимыми значениями. Пока мы не подтвердили конкретные методы записи,
Card Manager только показывает рекомендацию.

Он также НЕ меняет:
- цены
- остатки
- наличие
- описание
- название
- фото

Установка
---------
Полностью замени текущие файлы GitHub файлами из архива.

Render:
Build Command:
npm install

Start Command:
npm start

Environment:
PROM_TOKEN=твой Prom token
WRITE_ENABLED=true

Дополнительно можно оставить:
MAX_PRODUCTS=5000
KEYWORD_MIN=5
SCAN_CONCURRENCY=5
BATCH_SIZE=25

Как пользоваться
----------------
1. Deploy.
2. Открыть сайт.
3. Нажать "Сканировать весь каталог".
4. Подождать окончания. Для ~1600 товаров это может занять несколько минут.
5. Посмотреть фильтры и карточки.
6. Нажать "Исправить безопасно 25 товаров".
7. Система будет считать только те товары, где Prom подтвердил изменения.
8. Повторять партиями.

Лучше сначала проверить одну партию из 25, затем открыть 2-3 товара в Prom.
