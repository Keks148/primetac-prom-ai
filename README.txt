PrimeTac Group Audit v1.4.4a

Заменить в GitHub:
- src/prom.js

Что делает:
- НЕ меняет товары и группы Prom;
- через 8 секунд после запуска читает существующие группы Prom;
- пишет в Render лог [PROM_GROUPS_AUDIT];
- показывает id, name, parentId и полный путь каждой группы.

Это временный диагностический шаг, чтобы построить точную постоянную карту:
поставщик -> твоя существующая группа Prom.

Новые группы автоматически создаваться НЕ будут.
Нераспознанные/сомнительные товары в будущей выгрузке будут блокироваться как UNMAPPED.
