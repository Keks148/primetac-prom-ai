После Deploy v3.4.10 не запускайте импорт сразу, если восстановлен старый lock.
Программа сама проверит сохранённый import_id. Если старый PARTIAL уже полностью учёл все товары без изменений, lock будет снят автоматически.
После появления кнопки запуска нажмите «ПРОВЕРИТЬ И ИСПРАВИТЬ ВСЁ» один раз.
Новый импорт использует only_update=false, но в YML входят только товары из текущего каталога Prom, а updated_fields ограничен group + attributes.
