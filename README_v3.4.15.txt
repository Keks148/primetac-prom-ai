PrimeTac AUTO v3.4.15 VARIANT FAMILY PROBE

Что нового
- Сохраняет глубокий аудит v3.4.14: точные семьи из supplier XML group_id.
- Добавлен безопасный тест ОДНОЙ семьи разновидностей.
- Перед записью открывается preview выбранной семьи.
- Для теста выбирается только high-confidence supplier_group_id семья из 2–8 существующих товаров, у которой одна текущая группа Prom и уникальные заполненные размер/цвет.
- В YML всем товарам тестовой семьи задаётся одинаковый числовой offer group_id из XML поставщика.
- Импорт: only_update=true, mark_missing_product_as=none, updated_fields=[name]. Название отправляется текущее, цены/остатки/фото/описания/группа каталога не включены в список обновляемых полей.
- После импорта автомат проверяет Public API на variation_group_id / variation_base_id.
- Если минимум 2 позиции не стали связанными разновидностями, статус NO_EFFECT и массовое восстановление остаётся заблокировано.
- Массового восстановления в v3.4.15 НЕТ.

Порядок теста
1. Deploy.
2. Запустить аудит разновидностей.
3. Нажать «ПОДГОТОВИТЬ ТЕСТ 1 СЕМЬИ».
4. Проверить список товаров на preview.
5. Нажать «ЗАПУСТИТЬ ТЕСТ ЭТОЙ СЕМЬИ».
6. Дождаться VERIFIED.
7. Проверить эту карточку в кабинете Prom вручную.

Важно
Веб-приложение «Різновиди» в кабинете Prom должно быть подключено. Prom требует одинаковый group_id у товаров одной товарной группы и уникальные заполненные значения характеристик разновидностей.
