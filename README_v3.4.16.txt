PrimeTac AUTO v3.4.16 ADAPTIVE VARIANT PROBE

Что исправлено после сообщения «Не нашёл безопасную семью для теста»:
- точная XML group_id-семья больше НЕ обязана уже находиться в одном current group_id Prom;
- для тестовой семьи определяется реальная уже существующая целевая группа PrimeTac;
- если позиции одной модели были разбросаны по группам предыдущими импортами, тест может привести ТОЛЬКО эту семью к одной целевой группе;
- цена, наличие, остатки, фото и описания не обновляются;
- массового восстановления разновидностей по-прежнему нет;
- при невозможности выбрать семью /variants/probe/state показывает selection_diagnostics с причинами отсева.

Порядок:
1. Deploy.
2. Запустить аудит разновидностей.
3. Открыть «ТЕСТ 1 СЕМЬИ».
4. Проверить preview: XML group_id, список позиций, целевую группу.
5. Запустить тест только одной семьи.
6. Дождаться VERIFIED и вручную проверить карточку в Prom.
