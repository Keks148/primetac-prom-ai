PrimeTac AUTO v3.4.11 REAL PROM GROUPS PROBE

Цель: перестать пытаться создавать группы YML-импортом, если группы уже созданы в кабинете Prom.

1) /groups/refresh читает реальные группы Prom и сопоставляет их по именам/родителям с groups.json.
2) /groups/real-map показывает таблицу Наше имя -> реальный Prom ID.
3) /groups/probe меняет группу ровно у ОДНОГО товара через POST /products/edit с group_id и затем перепроверяет товар через GET /products/{id}.
4) Массовый перенос в этой версии намеренно НЕ запускается даже после успешного probe. Это диагностический безопасный этап перед массовой записью.
5) Старый YML-импорт групп на этапе ожидания mapping/probe не запускается.

После Deploy: нажать «Обновить сопоставление», открыть «Реальные группы Prom», затем «ТЕСТ 1 ТОВАРА».
