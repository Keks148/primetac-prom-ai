PrimeTac AUTO v3.4.3 DIAG ONE

Цель: не делать массовую запись. Тестируется РОВНО 1 товар.

Кнопка «ТЕСТ 1 ТОВАРА»:
- если свежего плана нет, сначала сама делает безопасный предпросмотр склада;
- выбирает один простой товар, желательно только с изменением quantity_in_stock;
- отправляет один POST /products/edit;
- показывает точный HTTP status и тело ответа Prom;
- затем повторно читает товар и проверяет, применилось ли изменение.

STOCK_WRITE_ENABLED может оставаться false. Массовая запись по-прежнему выключена.
Диагностический тест выполняется только после явного нажатия кнопки.
