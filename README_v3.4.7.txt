PrimeTac AUTO v3.4.7 GROUP VERIFY

Что исправлено:
1. YML <category id> — это идентификатор группы внутри импорт-файла. Он не обязан совпадать с внутренним ID группы, который Prom возвращает через API.
2. Проверка результата теперь получает /groups/list, связывает реальные ID групп Prom с названиями PrimeTac и проверяет товар по реальной группе/названию.
3. На главной странице показано: «Узлов PrimeTac найдено в Prom: X/46».
4. SUCCESS_NO_EFFECT больше не превращает весь AUTO-процесс в безликую фазу «Ошибка». Результат остаётся видимым как отдельный терминальный статус.
5. Старые lock-файлы v3.4.5/v3.4.6 поддерживаются: если в плане нет group_name, имя восстанавливается по groups.json.

После Deploy:
- не запускайте новый импорт сразу;
- нажмите ссылку «Проверить результат Prom» внизу страницы (это read-only проверка);
- смотрите «Фактически совпадает...» и «Узлов PrimeTac найдено в Prom».

Если узлов PrimeTac найдено много и товары совпали, предыдущий импорт на самом деле сработал, а старый код просто неверно сравнивал ID.
Если найдено 0/46, следующий шаг — отдельный безопасный bootstrap дерева групп, без повторной отправки всего каталога вслепую.
