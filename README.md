# PrimeTac Prom AI v10.1 — Manager Fix

Исправляет две проблемы интерфейса v10.

## 1. Старое правило «20% чистыми» больше не управляет рекомендацией цены

Текущая политика магазина:
**Prom = закупка Militaris +20%**

Поэтому верхняя статистика теперь показывает:
- Цена ровно +20%
- Цена съехала
- Поднять до +20%
- Снизить до +20%
- Убыток после Econom
- Чистая маржа после Econom <5%

Чистая маржа ≥20% / <20% остаётся только аналитикой в фильтрах.
Она больше не заставляет систему написать «Поднять цену» для всего каталога.

## 2. Ассортимент Militaris вне магазина сгруппирован

Раньше одинаковые названия XML могли появляться много раз:
например один Rip-Stop Hunter Pixel в разных вариантах/размерах.

Теперь менеджер группирует их по модели и показывает:
- одно название;
- диапазон цен;
- количество вариантов;
- количество параметров.

## Что видно по текущему скрину пользователя

После v10 менеджер уже обнаружил:
- 39 товаров без надёжного match;
- около 21 цены, которые ещё отличаются от правила +20%;
- 13 карточек с коротким описанием;
- 10 карточек со слабым названием;
- 0 убытков после Econom;
- некоторые товары с чистой маржой после Econom ниже 5%.

Это полезные реальные задачи. После установки v10.1 цифра «Поднять цену 1089» исчезнет.

## Установка

Заменить:
- `server.js`
- `public/index.html`

Environment Variables менять не нужно.
