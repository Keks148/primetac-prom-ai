# PrimeTac Prom AI v7.1

Исправление удобства ТОП-30 → AI-редактор.

## Исправлено
Раньше при нажатии «Открыть в AI-редакторе»:
- список ТОП-30 исчезал;
- редактор показывал только первые 500 товаров каталога;
- если выбранный кандидат был за пределами первых 500, выпадающий список мог стать пустым;
- после редактирования было трудно вернуться к тому же месту.

## Теперь
- AI-редактор содержит все товары каталога, а не первые 500.
- При открытии кандидата из ТОП-30 выбирается именно его ID.
- В редакторе показывается:
  - номер товара в ТОП-30;
  - его название;
  - «Предыдущий»;
  - «Вернуться к ТОП-30»;
  - «Следующий».
- Возврат в ТОП-30 автоматически прокручивает к тому же товару и подсвечивает его.
- Можно проходить ТОП-30 по одному товару, не разыскивая каждый заново.

## Обновление v7 → v7.1
Достаточно заменить в GitHub:
- `public/index.html`

`server.js` изменён только по номеру версии, поэтому его замена необязательна.

Environment Variables менять не нужно.
