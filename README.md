# PrimeTac Prom AI v11 — Price Guard

Главная задача v11: не дать обновлению XML снова оставить на Prom исходные цены поставщика.

## Price Guard

По умолчанию включён. Каждые 10 минут он:
1. обновляет XML Militaris;
2. перечитывает свежие цены Prom;
3. считает закупку по скидке бренда;
4. считает целевую цену `закупка × 1.20`;
5. находит все съехавшие цены;
6. автоматически возвращает их;
7. делает повторную проверку.

Если одновременно съехало 100+ товаров, это отмечается как массовая перезапись.

## Главный экран

Оставлены только: Менеджер, Price Guard, Каталог, Заказы, AI-редактор, Инструменты. Старые функции не удалены — они внутри `⋯ Инструменты`.

## После установки

Открой `🛡 Price Guard`, введи WRITE_PIN и нажми `🚨 Восстановить все цены`. После этого оставь Guard включённым.

## Важно

Если Render спит, внутренний таймер не выполняется. После пробуждения можно нажать `Проверить и восстановить сейчас`.

## Установка

Заменить `server.js` и `public/index.html`. Новые env необязательны, но по умолчанию Guard уже включён.
