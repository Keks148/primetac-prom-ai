# PrimeTac Prom AI v5

Добавлен безопасный AI-редактор товаров Prom.

## Возможности
- AI готовит новое описание на украинском.
- Рассчитывает новую цену по целевой валовой марже.
- Перед записью показывает предложение.
- Текст можно вручную исправить.
- Реальная запись требует отдельного WRITE_PIN.
- Массового автоматического изменения пока нет.
- Защита от случайного изменения цены более чем в диапазоне 50%–180% от текущей.

## Render Environment
Добавьте:
- WRITE_ENABLED=true
- WRITE_PIN=придумайте длинный секретный PIN

Существующие PROM_TOKEN, OPENAI_API_KEY, OPENAI_MODEL не меняйте.

## Как тестировать
1. Deploy v5.
2. Нажмите «Анализ всего каталога».
3. Откройте «AI-редактор».
4. Выберите один недорогой товар.
5. Сначала лучше изменить только описание.
6. Нажмите «Подготовить изменения AI».
7. Проверьте текст.
8. Введите WRITE_PIN и нажмите «ПРИМЕНИТЬ В PROM».
9. Проверьте карточку товара на Prom.

Важно: текущая версия отправляет изменение через официальный POST /products/edit.
Если Prom вернёт ошибку формата запроса, пришлите текст ошибки — подстроим payload под фактическую схему вашего API без массовых изменений.
