# PrimeTac Prom AI v10 — Smart Manager

v10 превращает панель из редактора цен в ежедневного управляющего магазином.

## Текущая политика цены

**Цена Prom = закупка Militaris + 20%**

Скидки поставщика:
- Salomon — 20% от сайта
- Helikon-Tex — 10%
- LOWA — 5%
- Belleville — 15%
- весь остальной товар — 15%

Комиссия Prom Econom считается отдельно и показывает реальную расчётную прибыль после Prom.
v10 не подменяет правило +20% требованием «20% чистыми».

## Новый раздел «🧠 МЕНЕДЖЕР»

Показывает:
- сколько цен съехало после изменения прайса поставщика;
- товары, которых нет у Militaris;
- товары, вернувшиеся в наличие;
- 39+ товаров без надёжного match;
- короткие/пустые описания;
- слабые названия;
- характеристики, которые есть в XML поставщика;
- товары с риском низкой или отрицательной прибыли после Econom;
- кандидатов из ассортимента Militaris, которых пока нет в текущем магазине.

## Синхронизация цен

Кнопка:
**«💰 Синхронизировать цены +20%»**

Меняет только товары, где текущая цена отличается от:
`закупка × 1.20`

## Автосинхронизация

В менеджере можно включить проверку цен поставщика по таймеру.
По умолчанию интервал — 60 минут.

Важно:
- таймер работает, пока Render-инстанс запущен;
- после рестарта состояние в памяти сбрасывается;
- если нужно включать автоматически после каждого рестарта, установить:
  `AUTO_PRICE_SYNC_DEFAULT=true`

## Снимок поставщика

«📌 Запомнить прайс поставщика» создаёт базовый снимок в памяти.
При следующем обновлении менеджер показывает:
- сколько цен изменилось;
- что закончилось;
- что вернулось в наличие.

Снимок в v10 хранится в памяти процесса и не является постоянной базой данных.

## Наличие

Militaris XML поддерживает `available`, `in_stock`, `quantity_in_stock` / `stock_quantity`.
v10 их читает и показывает расхождения.

Автоматическую запись наличия в Prom через `products/edit` v10 специально не включает:
мы не используем непроверенные поля API на реальном каталоге.
Следующий безопасный этап — тестовый YML sync на нескольких товарах.

## Характеристики

v10 читает `<param name="...">значение</param>` из XML Militaris.
Показывает их в панели для аудита.

Публичная документация Prom описывает до 100 характеристик на товар в YML.
Перед массовым импортом характеристик нужен тест на нескольких товарах, чтобы не перезаписать лишние данные.

## AI-карточки

«✨ Исправить карточки AI»:
- выбирает товары с плохим названием/описанием;
- берёт технические факты только из XML Militaris;
- не трогает цену;
- применяет только grounded-описания.

Начинайте с 10–20 карточек.

## Без match

«🔗 Разобрать без match» даёт по 3 наиболее вероятных кандидата Militaris.
Это рекомендации — v10 намеренно не привязывает сомнительные товары автоматически.

## Продажи

Раздел «Продажи» теперь показывает:
- оборот;
- валовую прибыль до Prom;
- ориентировочную прибыль после комиссии Econom.

Это оценка: фактическая комиссия конкретного заказа может отличаться от расчётной.

## Что ещё имеет смысл сделать дальше

После проверки v10:
1. безопасный YML sync наличия и характеристик;
2. постоянная база истории цен/остатков (например PostgreSQL);
3. статистика Prom из кабинета: показы → переходы → CTR → заказы;
4. автоматический рейтинг товаров для Econom / усиленного продвижения;
5. отдельный отчёт по отменам и прибыли заказа;
6. уведомления об изменениях поставщика.
