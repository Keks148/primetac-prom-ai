# PrimeTac Prom AI v4.1

Исправление v4.

## Главное
Кнопка «Продажи» в v4 могла долго висеть на «Считаю продажи…», потому что сервер заново
пересчитывал весь каталог и сопоставление Prom ↔ Militaris перед чтением заказов.

v4.1:
- кэширует готовый отчёт каталога;
- «Продажи» использует этот кэш и не пересчитывает 1144 товара повторно;
- если список заказов не содержит товарные строки, пробует получить детали заказов;
- понимает несколько вариантов полей товара/количества/цены;
- считает прибыль только там, где товар заказа удалось сопоставить;
- если товарных строк нет, оборот может учитываться по общей сумме заказа, но прибыль не выдумывается;
- анализ ограничен последними 100 заказами.
