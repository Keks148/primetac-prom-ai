# PrimeTac Prom AI v7

Версия для реального отбора товаров под рекламу.

## Что нового

### ТОП-30 для рекламы
Предварительный рейтинг без платного web search по марже, абсолютной прибыли и надёжности сопоставления.

### Светофор после анализа рынка
- GREEN — РЕКЛАМИРОВАТЬ
- YELLOW — ОСТАВИТЬ ОРГАНИЧЕСКИ
- RED — НЕ РЕКЛАМИРОВАТЬ

Финальный статус учитывает маржу, прибыль, число exact-конкурентов и конкурентность рекомендуемой цены.

### Более строгий match конкурентов
`exact` требует совпадения бренда и модели/линейки. Просто похожий товар должен идти как `close`.

### Описание без старого AI-мусора
Технические характеристики берутся только из supplierDescription XML Militaris. Старое описание Prom больше не является источником технических характеристик.

## Использование
1. Анализ всего каталога.
2. ТОП-30 для рекламы.
3. Открыть сильный товар в AI-редакторе.
4. Подготовить изменения AI.
5. Проверить рынок Prom.
6. GREEN — кандидат на рекламу; YELLOW — органика; RED — не рекламировать.
7. Проверить цену, название и описание.
8. Применить в Prom через WRITE_PIN.

Не запускайте web search по всем 1144 товарам сразу: сначала shortlist, затем 10–20 лучших.
