# PrimeTac Prom AI v9.2 — FIX массового +20%

Исправлена ошибка v9.1:

`Unexpected token '<', '<!DOCTYPE' ... is not valid JSON`

## Что было
Интерфейс v9.1 вызывал:
`POST /api/markup20/apply`

Но серверный маршрут для этого POST не попал в сборку.
Express возвращал HTML 404, поэтому браузер пытался разобрать HTML как JSON.

Результат:
- 1089/1089 ошибок;
- 0 цен изменено;
- Prom не получил массовые изменения.

## Что исправлено
- добавлен реальный `POST /api/markup20/apply`;
- WRITE_PIN теперь отправляется через `x-write-pin`, как и в основном редакторе;
- пакет до 50 товаров;
- каждый товар реально отправляется через существующий `promEditProduct`;
- если цена уже правильная — Prom не получает лишний запрос;
- после каждого пакета сбрасывается кэш каталога;
- HTML-ответ больше не маскируется под JSON-ошибку;
- добавлен `GET /api/markup20/status` для проверки, что новая серверная версия действительно задеплоена.

## Формула остаётся прежней
Цена Prom = закупка Militaris × 1.20

Скидка поставщика:
- Salomon — 20%
- Helikon-Tex — 10%
- LOWA — 5%
- Belleville — 15%
- остальное — 15%

Это 20% НАЦЕНКИ к закупке, а не 20% чистой прибыли после комиссии Prom.

## Обновление
Обязательно заменить ОБА файла:
- `server.js`
- `public/index.html`

После Render Deploy сначала открой:
`/api/markup20/status`

Должен вернуться JSON с:
- `"version":"9.2"`
- `"routeReady":true`

Только после этого запускай массовое изменение.

Для первого теста лучше обработать один пакет/несколько товаров и убедиться, что в журнале появились зелёные строки `✓ old → new`.
