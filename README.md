# PrimeTac Prom AI v10.2 — Manual Match

Версия для разбора товаров «Без match».

## Что появилось

В разделе:
**🧠 Менеджер → Разобрать без match**

для каждого товара Prom показываются кандидаты Militaris.

У каждого кандидата:
- название;
- бренд;
- цена поставщика;
- SKU;
- score совпадения;
- кнопка `✅ Это тот товар`;
- кнопка `❌ Не этот`.

## После «Это тот товар»

Система:
1. сохраняет ручное соответствие Prom ID → позиция Militaris;
2. пересчитывает закупку по правилам дропа;
3. показывает:
   - цену поставщика;
   - скидку;
   - закупку;
   - цену Prom по правилу `закупка +20%`;
   - комиссию Econom;
   - ориентировочную чистую прибыль;
   - ориентировочную чистую маржу;
4. предлагает кнопку:
   `💰 Применить цену +20% в Prom`.

Цена меняется только после отдельного нажатия.

## «Не этот»

Кандидат запоминается как отклонённый для конкретного товара Prom и больше ему не предлагается.
После этого система показывает следующих кандидатов.

## «Показать ещё»

Подгружает ещё 5 кандидатов Militaris для конкретного товара.

## «В Militaris такого товара нет»

Товар можно вручную пометить как отсутствующий в XML поставщика.
Он перестаёт мешать очереди «разобрать без match», но остаётся виден как unmatched в общем каталоге.

## Память ручных match

Сервер v10.2 хранит ручные match в памяти процесса Render.

Дополнительно браузер автоматически сохраняет резервную копию в `localStorage`.
Если Render перезапустился/был новый deploy:
- открыть `Разобрать без match`;
- нажать `↩ Восстановить сохранённые подтверждения`;
- ввести WRITE_PIN.

Это восстановит ручные соответствия из телефона обратно в серверную память.

Важно: localStorage привязан к браузеру/устройству. Не очищайте данные сайта до завершения разбора 39 товаров.

## Безопасность

Подтверждение match, отклонение кандидата, восстановление состояния и применение цены требуют WRITE_PIN.
PIN держится только в памяти открытой страницы (`window.MATCH_PIN`), а не сохраняется в localStorage.

## Установка

Заменить:
- `server.js`
- `public/index.html`

Environment Variables менять не нужно.
