# PrimeTac Prom AI v6.2

Исправления после теста v6.1.

## Рынок Prom
- Сначала используется официальный OpenAI Responses `web_search` с `allowed_domains: ["prom.ua"]`.
- Если этот запрос API отклонён, приложение автоматически делает один резервный web search без domain filter, но с инструкцией `site:prom.ua`.
- Если оба запроса не проходят, интерфейс теперь показывает точное сообщение OpenAI API (`message/type/code`), а не только `OpenAI web search error`.

## Описания
Промпт стал значительно строже:
- конкретные технические характеристики разрешены только если они явно присутствуют в исходном описании Prom или XML Militaris;
- запрещено выводить материал, состав, технологии и характеристики из названия или общих знаний;
- если фактов мало, описание становится коротким, а не выдуманным.

## Цена
Рыночная цена по-прежнему:
- учитывает закупку Militaris;
- не падает ниже выбранной минимальной маржи;
- сравнивает несколько найденных предложений Prom;
- не ориентируется исключительно на одиночный демпинг.

## Обновление
Заменить в GitHub:
- `server.js`
- `public/index.html`

Переменные Render не менять:
- PROM_TOKEN
- OPENAI_API_KEY
- OPENAI_MODEL
- OPENAI_WEB_MODEL=gpt-4.1-mini
- WRITE_ENABLED
- WRITE_PIN
- SELF_PROM_DOMAIN (опционально)

После Deploy:
1. Анализ всего каталога.
2. AI-редактор.
3. Подготовить изменения.
4. Проверить рынок Prom.
5. Если снова ошибка — пришлите её текст: теперь там будет точная причина от OpenAI API.
