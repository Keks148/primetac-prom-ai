# PrimeTac Prom AI v9.1 — режим «Уравнять +20%»

Эта версия добавляет отдельную кнопку:

**💰 УРАВНЯТЬ +20%**

Она не заменяет основной умный расчёт v9, а даёт отдельный массовый режим по запросу владельца магазина.

## Формула

1. Берём розничную цену Militaris из XML.
2. Считаем закупку по скидке дропа:
   - Salomon — минус 20% от сайта
   - Helikon-Tex — минус 10%
   - LOWA — минус 5%
   - Belleville — минус 15%
   - все остальные товары — минус 15%
3. Цена Prom = закупка × 1.20.
4. Цена округляется вверх до целой гривны, поэтому фактическая наценка не будет ниже 20%.

Пример:
- Militaris: 1000 грн
- обычный товар: закупка 850 грн
- Prom: 1020 грн

## Что делает кнопка

1. «Рассчитать весь каталог» — только предпросмотр.
2. Показывает:
   - сколько товаров можно обновить;
   - сколько цен будет повышено;
   - сколько снижено;
   - сколько товаров пропущено из-за ненадёжного match;
   - сколько после комиссии Econom окажутся в минусе/с очень маленькой чистой маржой.
3. После ввода WRITE_PIN:
   - проходит все надёжно сопоставленные товары;
   - отправляет цены в Prom партиями по 50;
   - показывает журнал изменений.

## Важное отличие

**+20% к закупке НЕ означает +20% чистой прибыли.**

Если закупка 850 грн, цена 1020 грн, а Prom Econom возьмёт 10% (102 грн), останется:
1020 - 850 - 102 = 68 грн.

То есть чистая прибыль ≈6.7% от продажи.

Этот режим сделан именно для временного выравнивания всех цен по единой наценке +20%.
