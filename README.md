# PrimeTac Prom AI v6

Главное изменение: рыночная цена теперь рассчитывается не только от закупки, а с учётом текущих предложений на Prom.ua.

## Как работает цена
1. Берём реальную расчётную закупку Militaris.
2. Задаём минимальную допустимую валовую маржу, например 12%.
3. Через OpenAI Web Search ищем актуальные предложения только на домене prom.ua.
4. Исключаем собственный магазин.
5. Стараемся использовать точные совпадения модели.
6. Не ориентируемся на один одиночный демпинговый товар.
7. Рекомендуем цену в нижней конкурентной части рынка, но не ниже минимально выгодной цены.

Это не гарантирует первое место в выдаче Prom: на выдачу также влияют рейтинг продавца, качество карточки, популярность и продвижение.

## Также исправлено
- AI предлагает название товара.
- Описание строится прежде всего на данных поставщика.
- HTML-теги декодируются и очищаются, чтобы Prom получал настоящий HTML, а не `&lt;strong&gt;`.
- AI не должен писать фразы про отсутствующие характеристики.

## Render
Добавьте новую переменную:
OPENAI_WEB_MODEL=gpt-4.1-mini

Опционально:
SELF_PROM_DOMAIN=cs4221574.prom.ua

Старые переменные не удалять:
PROM_TOKEN
OPENAI_API_KEY
OPENAI_MODEL
WRITE_ENABLED
WRITE_PIN

## Использование
1. Анализ всего каталога.
2. AI-редактор.
3. Выбрать товар.
4. Подготовить изменения.
5. Нажать «Проверить рынок Prom».
6. Система заменит техническую цену на рыночную безопасную цену.
7. Проверить название, описание и найденных конкурентов.
8. Ввести WRITE_PIN.
9. Применить в Prom.

## Стоимость веб-поиска
OpenAI Web Search тарифицируется отдельно от обычных токенов. Поэтому не стоит сразу проверять все 1144 товара.
Сначала проверяйте 10–30 наиболее перспективных позиций.
