# PrimeTac Prom AI v3

## Что нового
- Загрузка всего каталога Prom через пагинацию API (до 3000 товаров за один отчёт).
- Правила скидок Militaris:
  - Salomon — 20%
  - Helikon-Tex — 10%
  - LOWA — 5%
  - Belleville — 15%
  - остальные — 15%
- Валовая прибыль и маржа.
- Техническая рекомендованная цена для маржи 15%, 20% и 25%.
- Фильтры:
  - прибыльные;
  - маржа ≥20%;
  - маржа ≥15%;
  - низкая маржа;
  - убыток;
  - без сопоставления;
  - приблизительное сопоставление;
  - Salomon / Helikon-Tex / LOWA.
- Поиск по каталогу.
- AI-анализ товара с учетом рассчитанной закупки.
- Сводка по каталогу.
- Никаких автоматических изменений в Prom: версия остается read-only.

## Важно
`Рекоменд. 20%` — техническая цена для достижения валовой маржи 20%.
Она НЕ учитывает рынок, комиссию Prom, рекламу, доставку, возвраты или цены конкурентов.

## Как обновить v2 -> v3
В существующем GitHub-репозитории замените:
- `package.json`
- `server.js`
- `public/index.html`

После Commit Render автоматически задеплоит v3.

Переменные Render менять не нужно, если уже есть:
- PROM_TOKEN
- OPENAI_API_KEY
- OPENAI_MODEL=gpt-5-mini

## Первый запуск
1. Дождитесь статуса Live.
2. Откройте панель.
3. Нажмите «Обновить Militaris».
4. Нажмите «Анализ всего каталога».
5. Сначала проверьте фильтр «Приблизительный match».
6. Затем смотрите Salomon, Helikon-Tex и LOWA, чтобы убедиться в корректных скидках.
