# PrimeTac Prom AI v3.1

Главное изменение — строгий алгоритм сопоставления Prom ↔ Militaris.

v3 ошибочно мог связывать разные товары по совпавшему ID/SKU. v3.1 больше не доверяет ID Prom как идентификатору поставщика.

Сопоставление теперь требует:
- совпадение SKU только вместе с похожим названием/категорией;
- совместимость бренда;
- совместимость типа товара;
- разумное соотношение цен;
- либо сильное совпадение названий.

Лучше получить «Нет сопоставления», чем посчитать неправильную закупку.
